线上资料检查工具 · 使用说明
================================================================

一、干什么用
----------------------------------------------------------------
给一个工程编号，程序自己用 Everything 在本机/共享盘里找
「<工程编号>-b.线上资料.docx」，然后把整份资料拆开，对照
《线上燃气竣工资料填写规范与校验要点》逐项比对，列出会被退回的硬伤。

二、怎么用
----------------------------------------------------------------
1. 双击「线上资料检查.exe」→ 打开窗口   ← 推荐，不用装任何东西
2. 在「工程编号」里输入编号（如 NC23A005、ID25E021），回车或点「开始检查」
3. 十几秒后结果出来，红色=错误、橙色=警告、灰色=提示
4. 底部三个按钮：
     · 打开文档   —— 直接打开那份 docx 原件
     · 打开报告   —— 打开本次生成的检查报告（md 文本）
     · 报告文件夹 —— 历次报告都存在这里
5. 右上角「检查更新」按钮（2026-11-12 新增）：
     连 GitHub 查有没有新版本；有就弹窗显示版本号和更新说明，点「是」
     自动下载、替换文件并重新打开程序。整个目录里只有程序自身文件会被
     替换，「检查报告」和你自己放进去的文件都不会动。
     需要联网；连不上会提示，并能一键跳到 releases 页面手动下载。
     当前版本号显示在按钮左边（version.txt 里也能看到）。

整个文件夹可以整体拷到别的电脑（Windows 10/11 64 位），双击 exe 就能用，
不用装 Python。拷的时候必须连「_internal」文件夹一起拷，少一个都起不来。

另外还有两个备用入口（需要本机装了 Python 才用得了，一般不用管）：
  · 检查资料.bat    —— 用本机 Python 起同一个窗口
  · 命令行检查.bat  —— 命令行版，按提示输入编号，结果直接打印

想让程序自己改（2026-11-12 新增）：
  先检查一次（让它知道是哪个文件），再点底部绿色「自动修正」，确认后它会：
    · 单据编号：去掉中间的空格、按工序先后重排流水、消除重复
    · 项目人员信息表：把特种工登记表里有、人员表里没有的人补进去（岗位照抄）
  原文件先备份到同目录「_改前备份」，改完自动重新检查并弹窗告诉你改了几处。
  命令行版等价写法：python check.py <编号> --fix

  能自动改的只有"格式与编号"这类机械错误；数量、米数、缺哪张单、
  时间先后对不上这些要判断的，仍要人工处理。

搜到的同名文件有多份时（局域网里多台电脑都在备份），程序按
「修改时间新 → 路径短」自动挑第一份；打不开的副本会自动跳过试下一份。
也可以点「选文件…」直接指定文件。

三、查哪些项（能自动判的）
----------------------------------------------------------------
结构   目录列了但正文没有的单据、项目编号前后不一致、审批记录合并单元格错位
编号   单据编号重复、编号中间夹空格、GX 流水断号、螺纹连接与吹扫编号顺序颠倒
时间   报审四单是否依次递进（会审≤交底≤方案≤开工）、每张单审批时间是否倒流、
       首次审批是否早于单据填写时间、关键节点清单与单据实际时间是否对得上
工序   开挖→连接焊接→回填→隐蔽→吹扫→强度→严密→附件 的先后是否成立
次数   工序质量汇总表的检查次数与实际明细条数/单据张数是否一致
米数   材料核销单管材米数与竣工验收单工程量描述是否一致
试验   压力表读数是否只升不降、每张记录是否有 3 个节点、发泡剂检漏备注是否漏写、
       压力表有效期是否早于试验日期
人员   特种工工种是否与管材匹配（PE 管→PE 焊工、镀锌管→电工）、
       证件是否过期、特种工是否同时出现在项目人员信息表
收尾   核销/安全检查是否晚于竣工验收、竣工审批是否为最后一道

四、查不了、要人工看的
----------------------------------------------------------------
· 照片与表单上的时间是否一致（要肉眼对图）
· 签字、盖章、附件扫描件是否齐全
· 现场实际工程量（米数抄错但两处都一样时查不出来）
· 焊口数量与工程指令单是否一致

所以本工具是「先过一遍机器能查的」，剩下的还要自己翻一遍。

五、常见问题
----------------------------------------------------------------
Q: 提示「没搜到 xxx-b.线上资料.docx」
A: ① 编号写错；② 那份文件不在 Everything 索引里（换台电脑、或没开 Everything）；
   ③ 对方电脑关机，共享盘没挂上。

Q: 提示「搜到的 N 份副本都打不开」
A: 共享盘掉线了。在资源管理器里打开对应盘符确认能访问，或点「选文件…」手动选。

Q: 提示「没找到 es.exe」
A: 程序目录下 bin\es.exe 被删了。重新拷一份回去（Everything 官网的 ES 命令行工具），
   或把 Everything 装在默认路径也行（程序会自动找 C:\Program Files\Everything）。

Q: 结果里某条看着不对
A: 报告里的判断都带原始数值（比如「汇总表写 3 次；明细 63 条、单据 63 个」），
   对着数字看一眼就知道是资料错了还是口径特殊。

六、目录结构
----------------------------------------------------------------
修改资料程序\
  ├ 线上资料检查.exe        ← 双击这个（免安装）
  ├ _internal\              运行时依赖，别删别改名
  ├ 检查资料.bat            备用：用本机 Python 起窗口
  ├ 命令行检查.bat          备用：命令行版
  ├ _runtime.bat            给上面两个 bat 自动找 Python，不用管
  ├ ui.py                   窗口界面（含「检查更新」按钮）
  ├ updater.py              自动更新：查版本、下载整包、替换后重启
  ├ version.txt             当前版本号（改这里即可发新版）
  ├ check.py                检查主程序
  ├ checker\                解析与规则
  │   ├ docx_reader.py      docx → 单据/表格结构
  │   ├ rules.py            各项检查规则
  │   └ finder.py           Everything 搜索
  ├ bin\es.exe              Everything 命令行工具（源码版用；exe 已内置一份）
  ├ 检查报告\               历次检查报告（md）
  └ 线上燃气竣工资料填写规范与校验要点(1).md    规范原文

七、换电脑能不能用（2026-11-12 实测）
----------------------------------------------------------------
结论：能。整个文件夹拷过去就能跑，不装 Python、不装 Office/Word、
不改注册表、不装服务。Python 运行库、lxml、python-docx、.NET 桥、
es.exe 全部在 _internal 里。实测把 PATH 里的 Python 清空后 exe 照常
检查出报告，说明不依赖本机 Python。

硬性要求只有三条：
· Windows 10 / 11，64 位。（Win7 不行，Python 3.13 不支持）
· 系统自带 .NET Framework 4.8 —— Win10 1903 以上、Win11 都自带，不用装。
· 程序所在目录要能写：检查报告写在 exe 同级「检查报告」、
  临时文件写「_tmp」、自动修正的备份写在 docx 同目录「_改前备份」。
  所以别放 C:\Program Files 下，放桌面或 D 盘。

Everything 不是必须的，只影响「按编号自动搜」：
· 装了且 Everything 在后台运行 → 输入编号直接搜，最省事。
· 没装 / 没运行 → 会提示搜不到，这时点「选文件…」手动挑那份 docx，
  检查和自动修正照样全功能，结果一模一样。
· 想装的话，把 Everything 装在默认路径，本程序会自动认。
  注意：Everything 默认只索引本地磁盘，资料在映射盘 / 共享盘上时，
  要去 Everything「工具 → 选项 → 索引 → 文件夹 / 网络驱动器」把它加进来，
  否则照样搜不到，只能点「选文件…」。
· 别直接在 U 盘或网络盘里双击运行（.NET 加载慢且可能被安全策略挡），
  先整个文件夹拷到本地硬盘再开。

还要注意：
· 目标电脑得能访问资料所在的盘（K:、J: 这类映射盘要先连上，
  对方电脑关机 / 共享掉线就搜不到也打不开）。
· 不要只拷 exe 单个文件，必须连「_internal」整个文件夹一起拷。
· exe 没做数字签名，有的电脑首次运行会被 SmartScreen 或杀软拦一下：
  SmartScreen 点「更多信息」→「仍要运行」；杀软加白名单。
· 32 位系统跑不了（内置的是 64 位运行库）。

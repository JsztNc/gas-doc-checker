线上资料检查工具 · 使用说明
================================================================

一、干什么用
----------------------------------------------------------------
输入工程编号，程序自动在本机/共享盘找「<编号>-b.线上资料.docx」，
拆开整份资料对照《线上燃气竣工资料填写规范与校验要点》逐项比对，
列出会被退回的硬伤（错误/警告/提示三级）。

二、怎么用
----------------------------------------------------------------
1. 双击「线上资料检查.exe」→ 输入工程编号（如 NC23A005），回车或点「开始检查」
2. 十几秒出结果：红=错误、橙=警告、灰=提示（报告里都带原始数值，便于复核）
3. 底部按钮：打开文档 / 打开报告 / 报告文件夹
4. 右上角三个按钮：使用说明、检查更新、反馈（见第三、四节）
5. 搜不到时点「选文件…」直接指定那份 docx / pdf，检查与自动修正照样能用
   资料支持 Word(.docx) 与 文字型 PDF(.pdf) 两种格式；扫描件（图片型）PDF
   仍需先用 WPS/Adobe 的「PDF转Word(带OCR)」转成可复制文字的 Word 再查。

三、三个右上角按钮
----------------------------------------------------------------
· 使用说明：弹出本说明
· 检查更新：连 GitHub 查新版本，有则一键下载新 exe、替换自己并重启
            （只换这一个 exe，检查报告和你放目录里的其他文件都不动）
· 反馈：填类型+内容（联系方式选填），匿名提交到项目 GitHub Issues，
        无需登录；提交自动附上当前工程编号与正在做的操作，便于复现

四、自动修正（2026-11-12 新增）
----------------------------------------------------------------
先检查一次，再点底部绿色「自动修正」，确认后它会：
· 单据编号：去空格、按工序重排流水、消除重复
· 项目人员信息表：把特种工登记表有、人员表没有的人补进去（岗位照抄）
原文件先备份到同目录「_改前备份」，改完自动重查并告诉你改了几处。
命令行等价：python check.py <编号> --fix
注意：只能改「格式与编号」这类机械错误；数量、米数、缺哪张单、
      时间先后对不上这些要判断的，仍要人工。

五、查哪些项（机器能自动判的）
----------------------------------------------------------------
结构   目录有但正文没有的单据、项目编号前后不一致、审批记录合并单元格错位
编号   单据编号重复/夹空格、GX 流水断号、螺纹与吹扫编号顺序颠倒
时间   报审四单是否依次递进、审批时间是否倒流、首次审批是否早于填写时间
工序   开挖→连接焊接→回填→隐蔽→吹扫→强度→严密→附件 先后是否成立
次数   工序质量汇总表检查次数与明细/单据张数是否一致
米数   材料核销单管材米数与竣工验收单工程量是否一致
试验   压力表读数只升不降、每记录 3 个节点、发泡剂检漏备注、压力表有效期
人员   特种工工种与管材匹配、证件是否过期、是否同时出现在人员信息表
收尾   核销/安全检查是否晚于竣工验收、竣工审批是否为最后一道

查不了、要人工看的：照片与表单时间是否一致、签字盖章附件是否齐全、
现场实际工程量、焊口数量与指令单是否一致。本工具先过机器能查的，
剩下的还要自己翻一遍。

六、常见问题
----------------------------------------------------------------
Q: 提示「没搜到 xxx-b.线上资料.docx」
A: ① 编号写错；② Everything 没开 / 文件不在索引；③ 共享盘没连上。
   直接点「选文件…」手动指定那份 docx 即可，检查/修正照样能用。

Q: 双击 exe 闪退 / 弹「Failed to resolve Python.Runtime.Loader.Initialize」
A: 从网盘/邮件下载的会被 Windows 打「来自网络」标记，锁住内部 DLL。
   双击目录里「解除网络标记.bat」再打开（一次就行）；
   或右键 exe→属性→勾选「解除锁定」→确定。

Q: 换电脑能不能用
A: 能。只需拷这一个 exe，双击即跑，不装 Python/Office、不改注册表、不装服务。
   Python 运行库、lxml、python-docx、.NET 桥、es.exe、使用说明全打在里面。
   硬性要求：Win10/11 64 位（自带 .NET 4.8）；exe 所在目录要可写（别放
   C:\Program Files）；exe 无数字签名，首次可能被 SmartScreen/杀软拦，
   点「更多信息→仍要运行」或加白名单。32 位系统跑不了。
